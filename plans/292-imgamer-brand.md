# 292 — Rebrand panel FLVX → im.gamer (mint 手柄笑脸 logo, signature, restyled login)

Task `imgamer-brand` (11-22 TW). Base = `3.0.27-fork.159` (prod). Branch `feature/3.0.27-imgamer-brand`.
Design approved by the user from screenshots (gallery http://104.145.236.29:8791/imgamer-brand/, mint palette).
Panel only: frontend + backend default strings. No DB schema change, no agent change, no OTA.

## Decisions
- Brand colours in ONE place: `vite-frontend/src/config/brand.ts` (`BRAND_PALETTE`) → CSS vars `--brand-*`
  set once at start-up. Switching colour later (red / duo / purple …) = change one key there (all palettes
  from the design file are kept in that file). Static icons (favicon / PWA PNGs) are regenerated by
  `vite-frontend/scripts/brand-icons.mjs` from the same palette.
- Wordmark `im.gamer` = SVG paths (Nunito 900 outlines, no runtime font). Dot = accent colour.
- Logo = inline SVG with per-instance gradient ids (React `useId`), so several logos on one page never clash.
- Admin overrides keep working: `app_logo` replaces the logo image, `app_favicon` the tab icon; `app_name`
  other than `im.gamer` is shown as plain text instead of the wordmark.
- Panel interior keeps its blue primary; only brand surfaces (logo, wordmark, powered badge, login page) use mint.
- Technical identifiers stay: `flvx_agent`, service/binary names, CSS `flvx-*`, localStorage keys, API paths,
  repo URL, install scripts, sub-link ASCII fallback filename, admin-only technical texts (FLVX Core, 妙妙屋「FLVX 共享」…).
